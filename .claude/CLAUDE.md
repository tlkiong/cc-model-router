# cc-model-router

Claude Code mod. Source under `src/`, manifest under `.claude-plugin/`, hooks entry in `hooks/hooks.json`.

Follow `.aos/conventions.md` for naming, style, tooling and skills. Use bun, biome, and the project skills `comment-clean`, `git-commit`, `git-pr`.

`make check` runs lint, typecheck, `claude plugin validate .` and `claude plugin test .`.
